# AI Career Copilot

Full-stack AI-powered career counseling platform built to assist users with resume optimization, career report generation, and automated history tracking.

---

## Key Features

* **AI Career Analysis:** Generates insights based on user prompts and resumes using Groq AI.
* **Report Management:** Stores user history and reports securely using SQLite and SQLAlchemy.
* **User Authentication:** Provides signup, login, and dashboard functionalities.

---

## Tech Stack

* **Backend:** Flask, Python
* **Database:** SQLite, SQLAlchemy
* **Frontend:** HTML5, CSS3
* **AI Integration:** Groq API
